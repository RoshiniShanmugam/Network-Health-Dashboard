# Network Health Oversight Engine

An automated real-time Cisco Network Health Monitoring Dashboard built using Python, Flask, Netmiko, and Bootstrap.

## 🚀 Key Features
- **Real-Time Monitoring:** Fetches CPU Usage, Memory Utilization, and Device Status via SSH using Netmiko.
- **Multithreading Support:** Efficient background thread processing for concurrent network polling.
- **Auto-Recovery & Exception Handling:** Gracefully handles offline devices, authentication failures, and network timeouts.
- **Interactive UI:** Dynamic Web Dashboard built with Flask and Bootstrap.

## 🛠️ Tech Stack
- **Backend:** Python 3, Flask, Netmiko
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Networking:** Cisco IOS, SSHv2 Protocol
